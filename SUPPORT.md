# Support

| Need | Where |
|---|---|
| Bug report | GitHub Issues → `bug` template |
| Feature / module proposal | GitHub Issues → `feature` template |
| Spec amendment proposal | GitHub Issues → `spec-amendment` template (links the affected section) |
| Audit finding remediation | GitHub Issues → `finding-remediation` template (links the audit ID) |
| Security disclosure | GitHub Security Advisory (see SECURITY.md) |
| Operating questions | `docs/RUNBOOK.md` (created at milestone M1) |

Response expectations: bugs triaged within 2 business days; spec amendments discussed before any
spec file is touched — the contract changes in written amendments only.
